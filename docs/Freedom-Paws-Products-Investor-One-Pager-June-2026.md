## Problem & solution

| Problem | Our solution |
|---------|--------------|
| Lost pets: chip without photo match; shelters lack unified intake | **Freedom Paws ID** — biometric enroll + found intake + human-reviewed match |
| Pet parents want holistic guidance, not only acute vet visits | **ViT Diagnostics** — photo/video wellness + protocol recommendations |
| Clinics need phone-first CDS without replacing the DVM | **VitProScan** — cited differentials, PDF reports, chip scan in same app |
| Shelters need affordable multi-frequency scanners | **Universal Scan Kit** — OEM hardware + our software; donation program |
