## 1. Module overview

### Purpose

Turn SuperBud from a single cool video into a **locked, recognizable educator** that dog owners trust, share, and return to — while advancing Freedom Paws Wellness without hype or overclaim.

This module operationalizes the Desktop SuperBud AI Video Production System roadmap for a **solo founder**: batch character-consistent clips, edit once, ship many formats (YouTube long-form + Shorts / TikTok / Instagram Reels / quote cards / newsletter snippets).

### Mission alignment (non-negotiable)

Every SuperBud video must reinforce one or more of these Freedom Paws outcomes — not “AI pet content” for its own sake:

| Mission pillar | How SuperBud videos serve it |
|----------------|------------------------------|
| **Responsible AI** | ViT wellness education: symptoms → when to see a vet; never diagnose or prescribe |
| **Lost-dog ID** | Enroll education, shelter finder workflows, reunion *stories with consent* — no false “match live nationally” claims |
| **Evidence-based products** | Protocol education + Verified Partner standards (post-L5 for affiliate CTAs) |
| **Shelter give-back** | 10% net → 50% veteran dog orgs / 50% shelters (counsel-cleared wording only) |
| **Community acquisition** | Photo Booth UGC + adoption network traffic to `/adopt/tn` hub |

### Core principle: Character Lock

From the PDF — **the attached / archived reference video is the single source of truth**. Preserve across every episode:

- Face shape, wrinkles, expression  
- Fur color and grey facial markings (black pug)  
- Eye color, shape, and expression  
- Nose, ear shape, and muzzle  
- Body proportions and stocky pug build  
- Voice identity, energy, pacing, and tone  

**Only costume, cape, environment, and props change. The dog’s identity never changes.**

**Golden Rule prompt fragment (paste into every image/video prompt):**

> Use the locked SuperBud reference. Preserve the face, eyes, muzzle, fur markings, body proportions, and expression exactly. Do not alter the dog’s identity. Only replace the costume.

### Solo-founder honesty

| Realistic (you alone) | Stretch / later |
|-----------------------|-----------------|
| 1 master episode every 1–2 weeks → 5–8 Shorts | Daily long-form |
| Batch-script 4 episodes on Sunday | Full n8n auto-publish without review |
| CapCut + Buffer for speed | Final Cut Pro polish when revenue allows |
| Educational + soft CTA while `SITE_MODE=preview` | Hard affiliate / “shop partner” CTAs after L5 |
| Photo Booth UGC contests for volume | Paid ads at scale |

**Viral quality** comes from: locked face/voice, 3-second hooks, series binge, predictable schedule — not from overpromising product capabilities.

## 3. Step-by-step production (PDF roadmap)

Follow the PDF phases **in order**. Click-by-click below assumes Mac + browser accounts.

---

### Phase 0 — Lock the IP (Days 1–5)

**Goal:** One permanent source of truth so every AI generation, voice, and edit stays identical.

#### 0.1 Extract and archive master references

1. Locate the SuperBud **reference video** (source of truth from the PDF attachment / production archive).  
2. Create folder:  
   `~/Documents/Freedom Paws Wellness/brand/SuperBud-Master/`  
   Subfolders: `frames/` · `audio/` · `reference-sheet/` · `bible/` · `voice-id/`  
3. Open the video in QuickTime (or CapCut).  
4. Scrub and export stills (File → Export → or screenshot at full resolution) for at least:  
   - Flying pose (cape flowing)  
   - Podium pose (paws on podium)  
   - Close-up face  
   - Full body  
5. Extract audio: QuickTime → Edit → Copy → paste into Audacity/Descript **or** CapCut → detach audio → export WAV. Save as `SuperBud-voice-seed.wav`.  
6. Do **not** overwrite these files. Treat as read-only masters.

#### 0.2 Build the SuperBud Character Bible

Create `brand/SuperBud-Master/bible/SuperBud-Character-Bible.md` and fill:

| Section | Required content |
|---------|------------------|
| Visual lock | Face, fur/markings, eyes, nose, ears, muzzle wrinkles, stocky proportions |
| Expressions | Confident smile (slightly upward), determined flying face, warm speaking face |
| Personality | Trusted, upbeat, heroic-yet-approachable educator; speaks to dogs **and** humans; never clinical, never purely comedic |
| Voice | Tone, pacing, energy, catchphrases from reference |
| Signature poses | Flying + cape; podium; pointing/gesturing while teaching |
| Motion | Walking/running style; cape physics notes |
| Costume rule | Cape/shirt theme may change; pug identity never does |
| Compliance | Never diagnoses; directs to licensed / holistic veterinarian |

#### 0.3 Create multi-angle reference sheet

1. Open your strongest **image** model (Flux / Midjourney / equivalent) with **all** master frames attached as strict references.  
2. Generate once: front, three-quarter, profile, full-body + expression sheet (happy, serious, excited, teaching).  
3. Human QA: reject any face drift, wrong eye color, skinny body, or marking changes.  
4. Save winners as `SuperBud-Reference-Sheet-v1.png` (and PDF).  
5. **Freeze permanently.** Future costumes reference this sheet — do not “improve” the face later.

#### 0.4 Voice lock (ElevenLabs)

1. Go to [elevenlabs.io](https://elevenlabs.io) → Voices → **Clone**.  
2. Upload `SuperBud-voice-seed.wav` (and any additional clean SuperBud speech).  
3. Start with **Instant Voice Clone**.  
4. Generate a 15-second test of the signature greeting; A/B against the original seed.  
5. When you have **20–30+ minutes** of clean speech, upgrade to **Professional Voice Clone**.  
6. Rename voice permanently: `SuperBud-FP-Locked`. Copy Voice ID into `voice-id/README.md`.  
7. All future scripts use **only** this voice ID.

**Phase 0 deliverable:** Locked Character Bible + multi-view reference pack + permanent SuperBud voice ID.

### Phase 1 — Production pipeline architecture (Week 1–2)

**Goal:** Master-episode → multi-format system so one session yields **10–15** assets.

#### 1.1 Master episode skeleton (8–12 minutes)

| Time | Beat | Action |
|------|------|--------|
| 0–3s | Viral hook | Problem or surprising fact; SuperBud already on screen or flying in |
| ~5–15s | Signature intro | Locked greeting |
| | The Problem | Real owner pain point, plain language |
| | Science / explanation | Evidence-based; never medical diagnosis |
| | Demonstration | Visual example; costume matches topic |
| | CTA + series tease | One next action + “watch Episode N next” |

#### 1.2 Costume library (theme matches topic)

Veterinarian · Scientist · Explorer · Firefighter · Detective · Lifeguard · Astronaut · Park Ranger · Chef · Coach  

**Start with:** Veterinarian + Scientist only (PDF immediate next steps).

#### 1.3 Click-by-click: first costume plate

1. Open image model → attach `SuperBud-Reference-Sheet-v1.png` + close-up face frame.  
2. Prompt: Golden Rule + “SuperBud wearing a clean veterinarian coat and red Freedom Paws–style cape; podium classroom; identity unchanged.”  
3. Generate 4–8 variants; pick **one** plate with zero face drift.  
4. Save as `plates/vet-podium-01.png`.  
5. Repeat for Scientist.

#### 1.4 Click-by-click: animate a plate (Kling or Seedance)

1. Open Kling 3.0 **or** Seedance 2.0 → Image-to-Video.  
2. Upload frozen plate.  
3. Motion prompt example: “SuperBud stands at podium, subtle head turn, warm teaching expression, cape rests naturally, camera slow push-in, identity locked to reference.”  
4. Generate 5–10s clip. Reject if muzzle/eyes morph.  
5. Optional: Runway Gen-4.5 → refine camera only on the winning clip.

#### 1.5 Click-by-click: voice + optional lip-sync

1. Paste script into ElevenLabs → select `SuperBud-FP-Locked` → Generate.  
2. Download MP3/WAV.  
3. **Podium teach shots:** HeyGen (or ElevenLabs Avatars) → upload character still → attach audio → export talking clip.  
4. **B-roll / flying / demo:** keep silent AI clip; lay ElevenLabs audio in CapCut.

#### 1.6 Click-by-click: assemble in CapCut (solo default)

1. New project → 1080×1920 (Shorts) **and** duplicate timeline 1920×1080 (YouTube).  
2. Import: character clips, voice, intro sting (once you have one), logo end-card.  
3. Place hook clip at 0:00 (must show SuperBud or problem visual in first 3s).  
4. Auto-captions → style: high contrast, brand teal/navy text, never cover SuperBud’s face.  
5. Lower-third template: “SuperBud · Freedom Paws Wellness”.  
6. End screen: Subscribe / Follow + one CTA link (see Compliance).  
7. Export: master MP4 + separate 5–8 hook cuts (15–45s each).

### Phase 2 — Content system for virality & education

#### 2.1 One master → many assets

| Output | Count per master |
|--------|------------------|
| YouTube long-form | 1 |
| Shorts / TikTok / Reels | 5–8 (hook + one tip each) |
| Instagram carousel / Stories | 1–2 |
| Blog / FAQ snippet | 1 |
| Newsletter blurb | 1 |
| Thumbnails | 2–3 variants |
| Quote cards (SuperBud face) | 2–4 |

#### 2.2 Viral mechanics (do every time)

1. **First 3 seconds stop the scroll** — example hooks:  
   - “Did you know your dog could have parasites with zero obvious symptoms?”  
   - “This everyday backyard plant is toxic to dogs — most owners don’t know.”  
2. **End with a question** that invites comments.  
3. **Same branding:** intro music sting, SuperBud palette, lower-thirds, end-screen.  
4. **Predictable schedule** (see §6).  
5. **Cross-promote series** (“Watch Episode 3 next…”).

#### 2.3 Credibility guardrails (PDF — critical)

- Use language like “many veterinarians recommend” or “research shows.”  
- **Never diagnose or prescribe.**  
- Always direct owners to a **holistic veterinarian or their own veterinarian** for individual cases.  
- SuperBud = friendly trustworthy educator (the niche where most pet channels fail).

## 5. Compliance gates

Print this section. **No publish** if a gate fails.

### Gate 1 — Site mode & L5 (public promo)

| State | What you may publish | What you must not |
|-------|----------------------|-------------------|
| **`SITE_MODE=preview` / pre-L5** | Educational SuperBud content; soft “join waitlist”; Photo Booth demos; no scaled partner outreach | Implying full public commercial launch; live affiliate “Shop” CTAs; counsel-uncleared Terms claims |
| **Post-L5 + `SITE_MODE=public`** | Full CTAs to app modules; Verified Partner links with FTC; shelter Email 1 at scale | Still no false ID coverage claims |

**L5** = attorney Packet A sign-off (Terms, Privacy, biometric consent, ViT/CDS, give-back, disclosures). See Remaining Work Phase 0.

### Gate 2 — Never say / never imply

| Forbidden claim | Safer substitute |
|-----------------|------------------|
| “Match live nationally” / nationwide live matching | “Lost-dog ID tools for owners and shelter partners” + actual geo/pilot scope |
| “AI vet” / “diagnoses your dog” | “Wellness education check-in — not a diagnosis” |
| “Cures / treats [disease]” | “Supports wellness conversations with your veterinarian” |
| Guaranteed reunion | “Helps improve the chance of identification when used with shelters/owners” |
| Unverified charity/partner endorsement | Only cite documented programs; targets ≠ partners |
| “Dog Health Verified™” pre-clearance | “Freedom Paws Verified Partner” (descriptive) after program exists; TM search first |

### Gate 3 — Not veterinary advice (on-screen + description)

**End-card / description block (use every educational video):**

> SuperBud and Freedom Paws provide general pet wellness education only. This is not veterinary advice and not a diagnosis or treatment plan. Always consult your licensed veterinarian (or holistic veterinarian) for your individual dog.

### Gate 4 — FTC for affiliates & endorsements

- Any paid/affiliate relationship: clear **“may earn a commission”** (counsel-cleared final text).  
- App already drafts protocol affiliate disclosure language — mirror tone on social.  
- Influencer/UGC paid seeds: material connection disclosure (#ad / “paid partnership”) per FTC.  
- **Do not** paste production affiliate URLs until L5 + ACTIVATION-GATE decisions.  
- Soft educational “brands we study for quality” ≠ endorsement.

### Gate 5 — Marketing automation

Per `docs/marketing/ACTIVATION-GATE.md`: Buffer / n8n Workflow F stay **off** until you explicitly activate. Manual posting is fine.

### Gate 6 — IP & trademark

- Use **SuperBud™** / **Freedom Paws™** consistently in descriptions.  
- Do not claim ® until registered.  
- Character Bible consistency strengthens trademark distinctiveness over time.

### Pre-publish checklist (60 seconds)

- [ ] Face/voice match locked SuperBud (no drift)  
- [ ] No diagnosis / no “match live nationally”  
- [ ] Vet disclaimer in description  
- [ ] CTA matches SITE_MODE / L5 status  
- [ ] Affiliate disclosure if any partner product mentioned  
- [ ] Reunion/adoption faces have consent  
- [ ] Links go to correct hub (`/adopt/tn`, `/diagnostics`, `/id/enroll`, `/photobooth`)

## 6. Weekly production workflow

**Batch SuperBud clips → edit → schedule.** Designed for ~4–6 focused hours/week solo.

### Sunday — Batch factory (2.5–3.5 hr)

| Step | Time | Action |
|------|------|--------|
| 1 | 30–45 min | Script **one** master (or 2 Shorts-only scripts) in Claude with compliance pass |
| 2 | 20 min | ElevenLabs: generate all voice lines for the week |
| 3 | 45–60 min | Generate / refresh costume plates → I2V in Kling/Seedance (aim 6–12 raw clips) |
| 4 | 15 min | Reject drift; file winners in `weekly/YYYY-MM-DD/raw/` |
| 5 | 45–60 min | CapCut: cut master + 5–8 Shorts; burn captions; export |
| 6 | 15 min | Write captions (7 for Buffer queue pattern: 2 adopt, 2 ViT, 1 veteran/give-back, 1 Photo Booth, 1 ID — adapt from AI Marketing Plan Agent 6) |

### Monday–Saturday — Publish & engage (15–25 min/day)

| Day | Ship | Engage |
|-----|------|--------|
| Mon | Reel/Short #1 | Reply to every comment with a question |
| Tue | Reel #2 | Duet/stitch only if on-mission |
| Wed | Reel #3 or carousel | Shelter/partner DMs = human-only (no auto-send) |
| Thu | Reel #4 | Pin comment with disclaimer + CTA |
| Fri | Long-form YouTube *or* best Short rerun + Stories | Save analytics screenshot |
| Sat | Photo Booth / light UGC repost | Credit creators |

### Scheduling

- **Pre-activation:** Upload manually to IG / TikTok / YouTube Studio.  
- **Post-activation:** Buffer queue Mon–Sun ~10 AM local (Workflow F).  
- Cross-post the **same** Short to TikTok + IG Reels + YouTube Shorts; native upload beats bare re-share when possible.

### Monthly scale-up (Phase 3)

Once Sunday factory is muscle memory: script **4 masters** in one sitting; generate all voices Monday; plates Tuesday; edit Wednesday; schedule Thursday — then take Friday off content ops.

## 8. Success metrics

| Profile link CTR | Track with UTM: `?utm_source=ig&utm_medium=reel&utm_campaign=superbud` |
| Subscriber/follower growth | Steady > spiky vanity; prioritize returning viewers |

### Brand / IP health

| Metric | Check |
|--------|-------|
| Character consistency QA fail rate | Target &lt;10% of generations kept |
| Recognition | Unprompted “SuperBud” comments |
| Compliance incidents | **Zero** takedowns / vet-board complaints / FTC flags |

### Weekly scorecard (5 minutes every Friday)

1. Posts shipped vs plan  
2. Top hook (name it; reuse pattern)  
3. Worst retention drop-off (fix hook or pacing)  
4. CTA clicks (enroll / ViT / adopt / booth)
