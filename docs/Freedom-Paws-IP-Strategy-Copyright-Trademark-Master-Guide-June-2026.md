# 2. Can AI do the research?

## What AI **can** do well (use Cursor, ChatGPT, Claude)

| Task | How to use AI |
|------|----------------|
| Explain form fields | Paste USPTO/Copyright Office field names; ask what they mean |
| Generate search term lists | “List 30 TESS search variants for Freedom Paws pet software” |
| Summarize results **you paste** | Run TESS yourself → paste hit list → ask “flag high-risk conflicts” |
| Draft goods/services descriptions | Ask for ID Manual–style wording; **you verify** against USPTO ID Manual |
| Build checklists & worksheets | This document |
| Review your specimen screenshots | Upload screenshot; ask “does this show mark in commerce?” |
| Explain office action letters | Paste refusal text; ask for plain-English meaning |
| Copyright work-type guidance | “Is this literary work or computer program?” |

## What AI **cannot** replace

| Limitation | Why |
|------------|-----|
| **Live USPTO TESS search** | AI does not query the live trademark database unless you use a tool that does — **you must search tmsearch.uspto.gov yourself** |
| **Legal clearance opinion** | Only a licensed attorney can give you a formal “freedom to operate” opinion |
| **Guarantee registration** | USPTO examiners decide; AI cannot predict refusals |
| **Know your LLC status** | You must confirm entity name, date formed, state |
| **File for you** | You click submit and pay on copyright.gov / USPTO |
| **Detect all similar marks** | Phonetic/similar marks require human judgment |

## Best practice: **AI + you + official sites**

```
YOU search TESS / copyright.gov
    → paste results into AI
    → AI summarizes risks
    → YOU decide proceed / adjust mark / call lawyer
    → YOU file on official site
```

**Grade with AI assist:** Copyright research **4/5** · Trademark clearance **3.5/5** (still need your TESS hours)

# 3. Copyright vs trademark — quick comparison

| | **Copyright ©** | **Trademark ® / ™** |
|---|-----------------|----------------------|
| **Protects** | Specific creative works (text, code, images) | Brand names, logos, slogans in **commerce** |
| **Automatic?** | Yes when created; **registration** adds lawsuit benefits | Common-law from use; **federal reg** = nationwide priority |
| **Where to file** | [copyright.gov/registration](https://www.copyright.gov/registration/) | [uspto.gov/trademarks](https://www.uspto.gov/trademarks) |
| **Typical fee** | ~$45–65 per work (online) | ~$250–350 **per class** per mark |
| **DIY difficulty** | Moderate | Harder |
| **Freedom Paws DIY grade** | **3.5–4 / 5** | **2.5–3.5 / 5** |
| **Your priority items** | Binders, manuals, app code | Freedom Paws Wellness, SuperBud, paw logo |

### Step 5 — Rights & correspondence
