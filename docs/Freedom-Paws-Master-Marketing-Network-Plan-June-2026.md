## 1. Executive summary — the hub model

Freedom Paws is not ten separate businesses. It is **one network** with ten compartments that only work when **people and dogs move through the center**.

```
                    ┌─────────────────────────────────────┐
                    │         PUBLIC (families)            │
                    │  Framer story → app.freedompawsinc  │
                    └─────────────────┬───────────────────┘
                                      │
                    ┌─────────────────▼───────────────────┐
                    │   ADOPTION NETWORK (TN → national)   │  ◄── HUB
                    │   app.freedompawsinc.com/adopt/tn    │
                    └─────────────────┬───────────────────┘
          ┌───────────┬───────────────┼───────────────┬───────────┐
          ▼           ▼               ▼               ▼           ▼
      SHELTERS    MUNICIPAL      FREEDOM PAWS ID   VETERANS   AFFILIATES
      (private)   (MAS/MACC/YW)  (reunion)         (mission)  (revenue)
          │           │               │               │           │
          └───────────┴───────┬───────┴───────────────┴───────────┘
                              ▼
                    INSURANCE · VETS · PROTOCOLS · MONITOR
                              │
                              ▼
                    GRANTS · MEDIA · GIVE-BACK (10%)
```

**Strategic truth you identified:** Without **public adoption traffic**, shelters have no reason to publish listings, affiliates have no audience, insurance has no enrollment moments, ID has no enrollments, and veterans have no reunion stories to fund. **Adoption is the top of the funnel for the entire network.**

**Marketing priority order (June 2026 forward):**

| Rank | Compartment | Job |
|:----:|-------------|-----|
| 1 | **Public + Adoption Network** | Fill the hub — families browsing, sharing, adopting |
| 2 | **Shelters + Municipal** | Supply listings + found-dog intake + credibility |
| 3 | **Freedom Paws ID** | Convert adoptions + found dogs into enrolled pets |
| 4 | **Insurance + Holistic vets** | Monetize concern moments (ViT, ID, post-adoption) |
| 5 | **Nutrition & product affiliates** | Monetize protocol engagement |
| 6 | **Veteran dog orgs** | Mission moat, B2B2C seats, PR, give-back |
| 7 | **Grants + media** | Amplify proof without paid ads |
| 8 | **Consumer modules** (ViT, Photo Booth, protocols) | Daily habit + viral acquisition |

## 3. The Adoption Flywheel — why public adoption fills every leg

### The flywheel (one sentence)

**A family finds a dog on `/adopt/tn` → adopts from a partner shelter → enrolls Freedom Paws ID (optional) → buys gut/immune protocol → quotes insurance → tells their story → three friends browse adopt → shelter publishes more listings.**

### Stage-by-stage fill rate

| Flywheel stage | What fills | Without public adoption traffic |
|----------------|------------|--------------------------------|
| **Browse** | Directory page views, shelter profile views | Partners ask “why publish?” |
| **Inquire** | Calls/emails to shelters from listings | Shelters see no ROI |
| **Adopt** | Real handoffs (shelter-tracked) | ID enroll prompt never fires |
| **Enroll ID** | New owner biometric enroll | Reunion network stays empty |
| **ViT / protocols** | Post-adoption wellness anxiety | No new member spike |
| **Insurance** | ID complete + ViT urgent CTAs | Zero high-intent quotes |
| **Affiliates** | Protocol-linked purchases | No click volume |
| **Photo Booth** | Adoption day shares | No UGC moment |
| **Veteran story** | Service dog + adoption crossover | Mission stays abstract |
| **Grants** | “X adoptions + Y reunions” metrics | Weak grant applications |
| **Press** | “TN Adoption Network launches” | No human-interest hook |

### Your job as marketer

**Always drive traffic to the hub first** (`/adopt/tn`), then **branch** visitors to ID, ViT, insurance, and affiliates with contextual CTAs — never the reverse.
