## Flow

| Step | On this page | What you do |
| --- | --- | --- |
| 1 | See the counts | In draft and Needs approval have not been published. |
| 2 | Open the draft | Read the caption, the script, and any approved Canva link. |
| 3 | Save the video link | Paste the public https address of the finished MP4. |
| 4 | Approve, then send | Approve first. Then Send to Buffer once. |
| 5 | Confirm the queue in Buffer | One video card. You still publish. |

## 1. See the counts

The badge **Blocked** means the emergency stop is on. Leave it on. It covers the automation toggles at the bottom of the page. It does not grey out **Send to Buffer**.

## 2. Open the draft

1. A handoff from Studio makes one card per network.
2. Read **Caption** and **Script**. If the words are not the approved slate, click **Archive**.
3. Confirm the CTA: `/adopt/tn`, `/id`, `/diagnostics`, `/mypets`, `/photobooth`, or `/waitlist`.
4. An approved Canva file shows as a link. That file is not sent to Buffer.

## 3. Save the video link

Paste the public https link. Buffer downloads this file when the post publishes. Open the link in a private window first. It must play with no login.

## 4. Approve, then send

1. Click **Approve**.
2. Click **Send to Buffer** once.
3. **Send to Buffer OK** means the webhook accepted it.
4. **Send to Buffer OK (dry-run)** means Buffer did not receive it. The webhook is not set yet.
5. A red line means the webhook refused it. Do not click a second send until the first card is fixed.
6. Repeat for the other network cards. One send per card.

## 5. Confirm the queue in Buffer

Open Buffer. Confirm one video card, with no phone icon. Instagram says Reel. Facebook says Reel. YouTube says Short. X shows the video on the Freedom Paws queue. Leave **Publish Now** alone. Skip TikTok.
